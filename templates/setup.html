🎵 Welcome to Spotify Kiosk Player

Configure your Spotify credentials before you begin.

1 Spotify Developer Account

  1. Go to Spotify Developer Dashboard
  2. Log in with your Spotify account
  3. Click "Create app" (or "Create an App")
  4. Enter:
    • App name: Spotify Kiosk Player (or another name)
    • App description: Kiosk music player
    • Redirect URI: http://127.0.0.1:5000/callback
  5. Select: Web API
  6. Accept the terms and click "Save"
⚠️ Important: Redirect URI
Use the loopback IP address configured by the installer. The redirect URI must match exactly:
http://127.0.0.1:5000/callback

2 Get Your Client ID and Secret

  1. After creating your app, click its name in the dashboard
  2. Click "Settings"
  3. Copy your Client ID
  4. Click "View client secret" and copy it
  5. Keep these safe - you will need them shortly!

3 Create the .env File

Create a file named .env in the project root:

SPOTIFY_CLIENT_ID=your_client_id_here SPOTIFY_CLIENT_SECRET=your_client_secret_here SPOTIFY_REDIRECT_URI=http://127.0.0.1:5000/callback FLASK_SECRET_KEY=a_random_string_here

Replace the values with your own credentials from step 2.

For FLASK_SECRET_KEY, use a long, random secret value (for example, a generated UUID).

4 Restart the Server

  1. Stop the Flask server (Ctrl+C in the terminal)
  2. Start the server again: python app.py
  3. Refresh this page
✅ Ready?
After creating the .env file with the correct credentials, restart the server and refresh this page.
